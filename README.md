# BudgetTracker
BudgetTRacker is a personal Budgeting and epense tracking web application designed to help users manage their monthly finances. Users can record income and expenses, organinze transacations into categories, set monthly budgets and monitor their financial activity through a dashboard.

The application uses SOUTH AFRICAN RAND (ZAR) as its currency and provides a simple interface for managing personal finances.

#

# Features
* **User Authentication** - Register and login in securely to access a personal account
* **Dashboard** - View an overview of financial activity, including income, expenses and budget information
* **Transaction Management** - Add income and expense transactions
* **Category Management** - Create, edit and delete custom transaction categories
* **Budget Management** - Set monthly budgets for individual categories and monitor spending
* **Budget Monitoring** - Track spending against budgets, including remaining amounts and budget usage
* **Data Visualisation** - View financial information through dashboard charts.
